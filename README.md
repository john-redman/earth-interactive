# EarthInteractive

An interactive, true-to-scale 3D globe for the browser. Spin it, open any country for facts, compare the real sizes of countries with pop-out puzzle pieces, recolour the world by data, and play a daily geography challenge.

**Live:** https://john-redman.github.io/earth-interactive/

> Public source, all rights reserved — see [LICENSE](LICENSE).

## Features

| | |
|---|---|
| **Globe** | Three.js sphere with a calm satellite-style ocean (coastal shallows, slowly shifting light) with its major currents drawn as meandering streamlines and labelled with direction and strength, cargo ships on the main sea lanes, light clouds (desktop), atmosphere, softly twinkling stars, real-time day & night from the Sun's position (switchable) |
| **Three border views** | UN Standard · De Facto Control · Recognition Neutral — driven by an editable rules file ([docs/border-views.md](docs/border-views.md)) |
| **Country cards** | Capital, population & area with world rank, density, GDP, languages, currency, clickable neighbours, deep link |
| **True-size compare** | Countries lift out as curved puzzle pieces, sit side by side at the same latitude and can be dragged anywhere on the globe; pull up the compare bar for a side-by-side stats table, or make a square share image |
| **Search** | `/` or Ctrl/⌘ K — countries, capitals and alternative names |
| **Data lenses** | Population, density, GDP per person, area — quantile choropleth with legend |
| **Games** | *Daily Challenge* (same 5 countries for everyone, shareable result) and *Find it* (10 rounds); distance-based scoring, a line from a wrong guess to the answer |
| **Country of the day** | One country a day for everyone, with facts, from a chip at the top or the Play menu |
| **Flywheel spin** | The globe keeps its momentum; grab to stop. A hard flick starts *rollercoaster mode*: a screaming crowd |
| **Ads** | Left/right banner slots (160×600 → 120×240), hidden on small screens |
| **Recenter** | Bottom-right button (or `R` / `Home`) flies back to the start-up view and resumes the idle spin; the globe holds still while a country card is open |
| **Deep links** | `?c=FRA` · `?compare=FRA,DEU` · `?play=daily` · `?play=classic&round=…&beat=…` (a friend's challenge) · `?view=un` · `?lens=density` · `?embed=1` (in an iframe) |

## Quick start

No build step — it's static HTML + ES modules. Any static server works:

```bash
npm run dev            # serves on http://localhost:5173
# or: python3 -m http.server 5173
```

ES modules don't load from `file://`, so open it through a server.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Static server on port 5173 |
| `npm install` | Installs the two build-time tools (`d3-geo`, `polygon-clipping`), only needed for `build:data` |
| `npm run build:data` | Regenerates `data/world.js` and `data/ocean.png` from `tools/sources/` + `tools/views.config.mjs` |
| `npm run check` | Parses every module, validates the data, the modulepreload list and the offline cache list (CI) |
| `npm test` | Unit tests: geo maths, Sun, population clock, lenses, streaks, content tables (CI) |
| `npm run build:pages` | The site with the generated text pages into `dist-pages/` (preview; the deploy builds `_site`) |
| `npm run smoke` / `npm run qa` | Browser checks against a running server (`BASE=…`; needs Playwright) |
| `node tools/marketing/run.mjs` | Rebuilds the marketing kit and `og-image.png` (see `tools/marketing/README.md`) |
| `cd server && npm test` | Leaderboard API tests |

## Configuration

| What | Where |
|---|---|
| Border-view rules | `tools/views.config.mjs`, then `npm run build:data` |
| Ad snippets / sizes | `js/ads.js` (`ADS.slots.left/right/bottom.html`, `ADS.sizes`, `ADS.bottomSizes`) |
| Spin feel | `js/spin.js` (`SPIN.friction`, `SPIN.maxSpeed`) |
| Rollercoaster thresholds & samples | `js/thrills.js` (`THRILLS`) |
| Day & night look | the ocean and fill shaders (`js/globe.js`, `js/countries.js`); on/off is the corner switch |
| Colours & type | `:root` tokens in `css/style.css`; country palette in `js/countries.js` |
| Site URL, contact email, Ko-fi, GoatCounter | `tools/site.config.mjs` (+ `js/site.js`, `js/analytics.js`; see [docs/seo.md](docs/seo.md)) |
| Rendering quality | `js/perf.js` (`QUALITY` per tier); force a tier with `?quality=low` or `?quality=high` |

## Deploying

The site is hosted on **GitHub Pages** and deploys automatically on every push to `main`
via [`.github/workflows/pages.yml`](.github/workflows/pages.yml):

1. Runs `npm run check`.
2. Copies only the app files (`index.html`, `manifest.webmanifest`, `sw.js`, `og-image.png`, `css/`, `js/`, `data/`, `vendor/`, `icons/`, `sounds/`, plus `LICENSE` and notices) into `_site/`, builds the text pages, and stamps the service-worker cache version with the commit.
   `tools/`, `docs/`, `server/`, `app/`, `marketing/` and `node_modules/` are not published.
3. Uploads and deploys that artefact to https://john-redman.github.io/earth-interactive/.

One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
To redeploy without a code change, run the workflow manually from the **Actions** tab.

All asset paths are relative, so the app works from the `/earth-interactive/` sub-path (and from any other static host).
