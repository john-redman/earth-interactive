# Sounds

Optional recorded crowd-scream loops for rollercoaster mode (`js/thrills.js`).
Without files here the crowd is synthesised in the browser.

- 4–10 seconds each, trimmed to loop cleanly, mp3/ogg/wav.
- Royalty-free sources: Pixabay sound effects, Freesound (filter by **CC0**). Keep the licence/URL of every file in this README.
- Register them in `js/thrills.js`:

```js
samples: ['sounds/crowd-scream-1.mp3', 'sounds/crowd-scream-2.mp3', 'sounds/crowd-scream-3.mp3'],
```

Up to three are used; each becomes a group of riders circling the listener while the globe spins.
