# CLAUDE.md

Working notes for Claude Code (and humans) on EarthInteractive. Read this before changing code.

## What this is

A static, no-build web app: a true-to-scale Three.js globe with country cards, three border views, a true-size compare mode, data lenses, geography games and a "rollercoaster" audio easter egg. Product owner: John.
Design brief: modern, minimal, globe fills the screen, no menus/tabs beyond the small floating controls.

## Commands

```bash
npm run dev          # static server :5173 (no bundler, plain ES modules + importmap)
npm install          # only for the data build (d3-geo, polygon-clipping)
npm run build:data   # regenerate data/world.js and data/ocean.png — never hand-edit them
npm run check        # module syntax + data consistency (same as CI)
npm test             # unit tests (node:test, tools/test/): geo maths, Sun, population, lenses, content tables (CI too)
```

## Architecture in one breath

`index.html` holds every UI container and an importmap (`three` → `vendor/three/three.module.min.js`).
`js/main.js` owns app state (`mode`: browse | pick | compare | quiz), pointer & keyboard routing, deep links and the render loop, and wires the modules together. See `docs/architecture.md` for the per-module map.

Data flow: `tools/sources/*` + `tools/views.config.mjs` → `tools/build-data.mjs` → `data/world.js` (→ `tools/build-ocean.mjs` → `data/ocean.png`)
(`{ views: { un|defacto|neutral: { units: [{k,g,n,t,c,note,area,mod}] } }, geoms: [delta-encoded multipolygons], info: {key: facts} }`).
Unit keys are Natural Earth `ADM0_A3` codes (e.g. `FRA`), or `X_<SLUG>` for disputed overlays.

## Conventions

- Plain modern JS (ES2022), no framework, no TypeScript, no bundler. Keep it that way unless asked.
- Two-space indent, single quotes, semicolons. Small modules with one job each.
- Colours/typography live as tokens in `:root` of `css/style.css`. The app is deliberately dark-only.
- UI text: short, plain, active voice. No emoji in UI chrome (the shareable quiz result is the exception).
- Accessibility: keyboard reachable controls, `aria-*` on custom widgets, `prefers-reduced-motion` respected.
- Third-party code is vendored under `vendor/`; record new ones in `THIRD_PARTY_NOTICES.md`.

## Gotchas (learned the hard way)

- **Country fills** use `depthTest: false` + a per-fragment far-side discard, because large flat triangles sag below the ocean sphere. A **stencil** (`EqualStencilFunc` + `IncrementStencilOp`) makes each pixel blend once — without it shared triangle edges show bright seams. Compare pieces use their own stencil refs (100+id). The renderer needs `stencil: true`.
- **Country layer is batched** (`js/countries.js`): a view draws in 3 calls (all fills in one mesh, all borders in two `LineSegments2`, split at the ships' `renderOrder` 2.5), built on first show by `ensureBatch()`. Per-country style (fill colour, mix, bright, opacity, hatch + direction, line colour, opacity, width, dashed, shown) lives in a float `DataTexture` (one column per unit, `ROWS` rows) that `style()` writes and the shaders read by the `country` / `instanceCountry` attribute; dash distances restart per country. Never set style on the batch materials. A country that must draw out of order (selected, hovered, quiz-marked: border at `renderOrder` 3; raised: fill at 1.95 + glow) gets its own objects (`o.ovFill` / `o.ovLine`, pooled materials, geometry disposed on release) via `syncOverlays()`, and its part of the batch is hidden by the texture's show flag so nothing draws twice. There is no `o.fill` / `o.border` any more.
- **Triangulation**: earcut in lon/lat, then longest-edge bisection (`maxEdge` 6°, measured on the sphere: Δlon × cos lat). 4-way subdivision explodes the triangle count on earcut slivers — don't go back to it. Measuring in raw degrees turned Antarctica alone into ~200k triangles.
- **Mobile performance** (`js/perf.js`): touch devices get the `low` tier — no MSAA, pixel ratio ≤ 1.5, two ocean noise octaves, lighter spheres, borders simplified by 0.06° (98k → 31k segments; fills keep full detail), no `backdrop-filter` (`:root[data-quality="low"]` in CSS). The governor drops the pixel ratio in 0.25 steps when median frame time > 22 ms. `CountryLayer.cull()` hides countries behind the horizon every frame (sets `o.vis`; the batch collapses their vertices in the vertex shader via the style texture's show flag, overlays get `visible = false`); anything that needs a hidden country drawn must account for it. The country layer is ~3 draw calls on both tiers (was ~400). Test with `?quality=low` on desktop.
- **Service worker** (`sw.js`) serves everything stale-while-revalidate. The deploy stamps `VERSION` with the commit so each deploy gets a fresh cache; it is skipped on localhost. Install fetches `CORE` with `cache: 'no-cache'` (always revalidated, so never stale, but unchanged files come back 304 from the HTTP cache instead of being downloaded again on every deploy); don't go back to `'reload'`. New files the app needs offline go in `CORE`. When a new worker takes control within 10 s of page load (and there was a previous worker), `main.js` reloads once per session so returning visitors see the new deploy, not the cached one.
- **Data loads via `js/load.js`** (streamed fetch → blob `import()`), not a static import, so the loader can show progress. The first view is built with `layer.buildAsync()` in 12 ms slices.
- **Phone layout**: the country card is a bottom sheet that opens as a 196 px peek; `js/sheet-drag.js` makes it (and the compare stats panel) follow the finger and settle by position + flick velocity. Below 1100 px wide the side ads give way to one bottom banner; the stage shrinks by `--ad-h` so nothing overlaps it. **A slot with no ad takes no room on the public site**; the grey placeholders show only on localhost (so QA and smoke still see the ad layout) or with `?ads=preview`.
- **Draw order is fixed per country**: by type then index (`o.fillOrder` 1.x, `o.lineOrder` 2.x; 3 = highlighted). The batches keep exactly this order in their buffers (fills and stencil: first drawn wins; coincident shared borders: last drawn on top), so don't reorder them, e.g. into spatial chunks, without checking neighbours. Overlays sort by explicit `renderOrder`s (1.95 raised fill, `lineOrder` or 3 for borders, 2.99 glow). Don't go back to equal render orders: three.js would sort coincident shared borders by camera distance and they flicker as the globe turns. Phone borders use `simplifyShared()` (cut where the neighbour set changes, DP per stretch) so neighbours stay identical — independent per-country simplification makes double lines.
- **Card placement**: on desktop the card docks on the right; `frameBesideCard()` then flies the globe so the country's main landmass (`compare.shapeFor(o)`: centroid + reach) fills the free space left of it (above the 196 px peek on phones), using the exact perspective projection. Pins, fly-tos and game distances use `compare.anchorFor(o)`: the main-landmass centre if it is on land, else the nearest point that is (France's whole-country centroid lies in Spain, Japan's main-landmass centre in the Sea of Japan; 34 countries per view needed this).
- **View switch** clears the pin, tag and card: the same spot can belong to another country in the new view. **Games** switch to the UN view (`GAME_VIEW`) and restore the previous view on exit unless the player changed it.
- **Games lock the view** (switching mid-round would lose its highlights; a toast explains) and hide the dock on both sizes. Compare keeps the dock on both sizes.
- **Phone half-rate**: on the low tier `frame()` draws every other frame while nothing moves (no flight, zoom, spin, drag, compare animation or touch). Anything that animates on its own and must stay smooth needs to be added to that `calm` check.
- **Search focuses synchronously** in `open()`: iOS only raises the keyboard for a focus made inside the tap. Don't move it back into a `requestAnimationFrame`.
- **Share image** keeps the last rendered PNG; if the share sheet is refused (slow render outlived the tap), it returns `'retry'` and the second tap shares at once.
- **Phone card sheet**: growing or shrinking it calls `onSheet` → `frameBesideCard()` so the country stays visible above it.
- **Selection flow**: tap → `openCountry()` shows the SVG pin (`js/pin.js`, a DOM overlay placed at the projected anchor each frame, crisp at any DPR) and the DOM tag; the card opens only via `openInfo()`. Escape / card ✕ go card → tag → nothing. Compare shows `#compare-pill`; the full `#compare-bar` opens from it.
- **Backend** (`server/`, Cloudflare Worker + D1) is not published by Pages. `js/net/profanity.js` is the one copy of the name filter; the Worker re-exports it. With `API_BASE` empty in `js/net/api.js` every call resolves to null and the leaderboard stays hidden. Run `cd server && npm test`. See `docs/backend.md`.
- **Fills are opaque** (`uOpacity` 1, `uMix` tones the palette towards ocean blue per state) and **border lines discard back-facing fragments** (`vFace` injected via `onBeforeCompile` in `lineMaterial()`). Both are needed: the ocean sphere is faceted, so depth testing alone lets far-side lines poke out at the horizon.
- **UI sounds** live in `js/sfx.js`: synthesised tones (keep them, the owner likes them) plus recorded samples from `sounds/` for the airy parts (swipe/reversed swipe for open/close, plop for the pin, click/reversed click for compare pieces). One delegated click listener maps buttons to sounds; toggles with `aria-expanded="true"` play `close`. Respects `thrills.muted`. Music (`js/music.js`) is separate, **on by default** for a first visit (starts with the first tap or key press: autoplay rules), remembered in localStorage. `sw.js` skips `/sounds/` and Range requests.
- **Highlights**: `CountryLayer.raise()` lifts the selected country (steady white glow) and quiz answers (`target`/`good`: thick white border + bright dashes running round a smoothed outline). Raised fills draw over neighbours (stencil Always while raised).
- **Games auto-advance**: after an answer the Next button fills up (`.qz-fill`, `AUTO_MS` in `quiz.js`: 2.6 s right, 5.2 s miss, 4.2 s Show me) and the game moves on when it ends; Next still works at once, and pointing at the panel pauses the fill. The fill keeps its real length under reduced motion (it is a timer).
- **Quiz guesses** are two-step: a tap drops the pin with a Confirm / Not here tag (`proposeGuess` → `confirmGuess`); Enter confirms, Escape cancels. The Enter handlers call `preventDefault()`: answering moves focus to "Next country", and the same Enter would otherwise press it and skip the result.
- **Card animations**: `.in`/`.out` classes with `animation-fill-mode` backwards/forwards only, so `sheet-drag` can still move cards; `hideAnimated()` hides after the out animation.
- **LineMaterial resolution** is in CSS pixels (`layer.resizeLines()` on resize); extra line materials must be registered.
- **Rotation is owned by `js/spin.js`**, not OrbitControls (`enableRotate = false`). OrbitControls only does pinch zoom. **A swipe adds to the spin it already has** (release velocity is added to the running momentum; the idle auto-rotate turns into momentum on touch); a finger resting for `holdStopMs` (140 ms), a tap, or a drag against the spin stops it. **Arrow keys** go through `spin.keys()` every frame (→ turns the globe's face to the right; up/down unchanged): a press answers at once, holding ramps the speed up (scaled by zoom, Shift ×2); release after `keyCoastAfter` (0.9 s) coasts, a shorter press settles fast (`quickStop`). Don't go back to adding a fixed step per keydown (auto-repeat made it choppy). The idle auto-rotate is also spin's (`globe.autoRotate`, eased in/out; OrbitControls' own auto-rotate is off because it stops during a pinch). **Zoom never stops or starts rotation**: wheel, +/- and **Shift / Ctrl on their own** (in / out: a clean tap steps on release, holding glides after `MOD_HOLD` 300 ms; any other key, click or wheel during the press cancels it, so Shift+Tab, Shift+arrows and Ctrl+K never zoom; `zoomByMods()` in `frame()`) use the eased `globe.zoomBy()`, and a second finger within `PINCH_MS` gives the spin back (`spin.pinch()`). Idle auto-rotate restarts 12 s after the last grab unless something holds it (`globe.hold('card', true)` while a country card is open; `globe.lockAuto` during compare). `globe.flyHome()` + `globe.resumeAuto()` power the recenter button.
- **Click vs drag**: a click is < 6 px movement and < 650 ms; anything else is a spin. Keep this — it's a core UX promise.
- **Audio** must be unlocked from a pointer gesture (`thrills.unlock()`). A hidden tab suspends the ride audio (the render loop that fades it stops). The ride audio is only the owner's screaming recording (`THRILLS.samples`), played straight — no wind, drone/dread bed, synthesised voices, HRTF orbit or playback-rate changes (the owner heard them as hum and wobble). The context suspends after 3 s of silence.
- **Compare has no sound of its own** on pressing Compare (the owner disliked the bell; a recorded one will come) — only the piece's snap-out click.
- **Pin drop sound**: `tap` is just the plop, scheduled at `PIN_LANDS` (0.16 s, the landing frame of `@keyframes pinDrop`) minus its 22 ms peak. Change both together.
- **Free move** (`liftCountry(o, intent)` in `main.js`): the tag's **Move** button, or press-and-hold (`HOLD_MS` 420, within the 6 px slop) on the *pinned* country only, lifts it with `compare.preview()` and (for the hold) starts dragging in the same gesture. Move and Compare share the one `pick` state; `intent` only changes the banner's wording. Tapping another country then runs `compare.start(a, b)` with the same piece. Holding anything else still just spins. The canvas suppresses the touch context menu. **Arrow keys** move the lifted piece (screen-relative, ~180 px/s, Shift faster; `heldArrows` + `moveByKeys()` in `frame()`); in a comparison they move the last-dragged piece, 1 / 2 pick one. Arrows still spin the globe when nothing is lifted.
- **First visit** (`js/intro.js`, `ei-intro`): a finger swipes across the globe three times (static under reduced motion) and leaves at the first touch, wheel or key. After the first country tap, the tag shows a one-line tip once (`ei-tip-tag`).
- **Keyboard & screen readers**: the canvas is focusable (a ring marks the middle while it has keyboard focus); Enter on it acts as a click in the middle of the view (select, compare, guess). After Enter selects a country, focus goes to the tag's **Move** button and Tab / Shift+Tab go round Move, Compare, Info (`focusTag()`); Info by keyboard focuses the card's close button; Escape steps back (card → tag with focus on Info → nothing with focus on the globe). An arrow key while a country is pinned closes the pin and turns the globe (inside an open card, arrows scroll it). Move/Compare by keyboard hand focus back to the globe; in **Compare** (`pickIntent`) the arrows aim the globe and Enter picks the middle country, in **Move** they carry the piece. `announce()` in `main.js` writes to the polite `#sr-live` region (selection, comparison result).
- **No WebGL / context lost / too old**: `#no-3d` replaces the blank screen with links to the text pages (and a Reload button after a lost context). Browsers without import maps (Safari < 16.4, i.e. iOS 15 and early 16) can't even start `main.js`: the inline head script in `index.html` marks `data-old` (`HTMLScriptElement.supports('importmap')`), and CSS shows `#no-3d` with an "update your browser" line and hides the loader.
- **Errors from visitors** are counted as GoatCounter events (`error/<message @ file:line>`, once per message per visit, max 10) by `js/analytics.js`.
- **First load**: `index.html` modulepreloads every module in the static import graph of `main.js` (and preloads `data/world.js`); `npm run check` fails if the list drifts, and prints the missing `<link>`.
- **World population** (`js/popclock.js`): UN WPP 2024 base and rates, ticks every 250 ms only while shown. Shown when zoomed out (distance / fit > 0.84, hides < 0.8), after the hint is gone, and not with `quiz-on`, `comparing`, `picking`, `lens-on`, `card-open` or `menu-open` (the phone links menu). Phone: two rows above the brand.
- **Compare pick**: pressing Compare calls `compare.preview(a)` — the first piece lifts out at once and can be dragged while choosing; `start(a, b)` reuses it. `end()` sinks it back; `flushEnd()` finishes a pending sink before anything new starts.
- **Ocean** (`oceanMaterial()` in `globe.js`): calm and still (owner: "calming and still"). Medium satellite blue with a broad still tone variation, subtle teal shallows, and slowly wandering patches where the light shifts a little. **No waves or crests on any device** (the owner removed them; swell lines read as stretch marks). Glint follows the real Sun while day & night is on. `data/ocean.png`: R closeness to the coast, G room for clouds, B land.
- **Ships** (`js/ships.js`): ~84 low-poly cartoon cargo ships (container ships and tankers: `aPart` in the geometry, per-instance `aKind`; mostly tankers on the Gulf lanes) on hand-drawn sea lanes (`ROUTES`, [lon, lat] waypoints between big ports) in **one `InstancedMesh`** (custom shader, flat baked shading, hull colour per instance, `renderOrder` 2.5). They sail both ways keeping right, shrink into port at the ends, and grow with the globe on screen (`SHIP_PX`: ~6 px at globe view, ~30 px at the closest zoom); they skip the far side in the vertex shader, dim at night and hide under a data lens. Wakes are a second instanced mesh sharing the ships' `instanceMatrix` (soft foam fan: two spreading arms + white water behind the stern, shaded in the fragment shader), shown only once ships are over ~9 px. All tiers. Lanes only cross land at the Suez and Panama canals: re-check with a pick sweep along `ships.lanes` after editing waypoints (the coastline data is coarse; the Singapore Strait only has room near 1.25° N).
- **Clouds** (`js/clouds.js`, **desktop only**: `TIER === 'high'`): one shell at r 1.005 with a 4-octave fbm, drifting with the prevailing winds (west in the trades, east in the westerlies) using two crossfaded phases (`PERIOD` 300 s) so the drift never shears into streaks. Masked by `ocean.png` G (`tools/build-ocean.mjs`): none within ~150 km of a landmass, full beyond ~450 km; islands under 30,000 km² don't count, so clouds drift over them instead of parting round them. `renderOrder` 2.9 (after fills, so a small island sits under a cloud). Very light (opacity 0.34), dim at night, fade out under a data lens.
- **Currents** (`js/currents.js`): painted on the globe like the type on a real globe, fixed to the Earth. 33 currents (`CURRENTS`: 35 entries, the ACC in three stretches; [lon, lat] along each current's charted mean axis) are a faint *lighter* sheen (one merged mesh, `renderOrder` −5, radius 1.0016) with real-looking meanders (`MEANDER` / `WAVE` by strength; still along the coast until `free`, scaled by `meander`), threaded with four streamlines that weave across the ribbon and carry streaks downstream, fastest in the core (`fwidth` keeps them at least a pixel wide), tinted faintly warm or cool (`warm`); never a dark band (the owner read the dark ribbons as scars). After editing waypoints or a label's `at` / `side`, sweep for land: `c._path.at(u)` and every vertex of the label mesh through `layer.pick()` must be water (the stencil would cut a label short on an island). They are dim at globe view and come up as you zoom in, and dim to half while a card, game or compare is open. Names (strength, typical m/s, an arrow drawn as a shape since the font has no arrow glyph, soft dark halo) and ocean names are text from one canvas atlas laid on strips on the sphere (one merged mesh, `renderOrder` −4), spaced evenly by arc length so letters keep their size: current names sit on **one smooth bow** (quadratic arc through the start, middle and end of their stretch, softened) on the given `side`; ocean names follow their parallel below 55°, and run straight (great circle) nearer the poles. `currents.spots` lists every label's centre for checks. Reading direction is chosen so text is upright with north up. The label mesh draws at `renderOrder` 2.95 without depth test, over ships and clouds, and uses the stencil (equal 0) so it never prints over land or a lifted compare piece (fills write 1, pieces 100+). Fade by zoom (major currents first, ocean names step back up close), toward the rim, and current names hide in games/compare/card (body classes); a data lens hides everything. No DOM labels, nothing clickable.
- **Stars** (`stars()` in `globe.js`) sit in three depth layers (`STAR_LAYERS`) that follow only 25 / 45 / 70 % of the camera's turn (`tickStars()`, incremental quaternions, so no jump when angles wrap): parallax behind a spinning globe. Off under reduced motion. They are spread over the whole sky, but the 35° camera sees only ~5% of it: the counts in `perf.js` (2600 / 3800) give roughly 150 on screen. Normal blending with alpha falloff, never additive (the canvas is transparent and additive paints dark squares).
- **Day & night switch** (`#daynight-toggle`, `ei-daynight` in localStorage, on by default): `tickNight()` eases `SKY.uNight` (a 0–1 strength) to 1 or 0 (always 0 under a data lens); the look of night (dark moonlit blue, sharp terminator, warm dusk line) lives in the ocean and fill shaders. Don't set `uNight` directly elsewhere.
- **Games**: a wrong guess draws `MissLine` (guess → answer centroid, the same points the km figure uses) and `flyToBoth()` frames both; `onMiss(null)` clears it on next/finish/exit. Right/wrong chimes (`sounds/game-correct.mp3`, `game-wrong.mp3`) play only for real guesses, not "Show me".
- **Embed mode** (`?embed=1`): an inline script in `index.html`'s head sets `data-embed` on `<html>` before the first paint; `:root[data-embed]` hides the dock, site links, brand, chips, population strip, ads and music button. `main.js` turns ads off, keeps music from starting by itself (`createMusic(…, { autostart })`) and adds `.embed-open` ("Open the full globe", current address minus `embed`). The credit line stays (ODbL attribution).
- **Challenge links**: every Find it round is seeded (`round`, 6 base-36 chars; `mulberry32(hash('ei-round-' + round))`), and its result link is `?play=classic&round=…&beat=<score>`, which replays the same ten countries with that score to beat. `round` and `beat` are dropped from the address once the game starts, like `play`.
- **Daily streak** (`dailyStreak()` in `quiz.js`): counts consecutive `ei-daily-YYYY-MM-DD` results back from the game's day, stepping from local noon so a daylight-saving change never skips a day; shown on the Daily end screen and in its share text, with `untilTomorrow()` for the next one. On phones (coarse pointer + `navigator.share`) the result button is **Share result** (share sheet, clipboard fallback). **`?lens=`** deep link: `lensKey` starts from it and `applyLens()` writes it back with `setParam`.
- **Country of the day** (`js/daily-country.js`): same seed scheme as the Daily Challenge (local date) with its own salt; only countries in all three views. Chip shows once a day until opened or dismissed (`ei-cotd-seen`); also in the Play menu. Its facts appear as a note in that country's card.
- **Compare share image** (`js/share-image.js`): drawn on a 2D canvas with a Lambert equal-area projection per country at one shared km scale, so sizes stay true. Flags are fetched as SVG text and given a width/height before `drawImage`.
- **Phone footer**: the site links fold into a menu that opens upward from the brand (`js/site-menu.js`; `#brand-btn` with a down caret that turns up when open; Escape, a tap elsewhere or a link closes it, and Escape stops there). On desktop the brand is plain text (`tabIndex -1`, no `aria-expanded`) and the links stay a row. `--links-h` (a ResizeObserver on `.site-links`) is 0 on phones and lifts nothing there any more.
- **Border views are editorial and politically sensitive.** Change `tools/views.config.mjs` only on explicit request, explain the change in the PR, and update `docs/border-views.md`.
- `data/world.js` is ~1.1 MB and generated; CI fails if it is stale relative to the sources.
- Quiz questions only use keys that are a `country` in **all three** views, so a game survives view switches.
- **Population double counts**: Northern Cyprus and Somaliland are inside Cyprus's and Somalia's figures (`COUNTED_WITHIN` in `views.config.mjs` → `info[k].within`); their cards say so in the views that show them apart, and totals (e.g. world and region figures on the text pages) skip them.
- **Text/SEO pages** (`docs/seo.md`): `about.html` … `contact.html` are hand-written; `countries/` (incl. `countries/region/`, `countries/ranking/`), `compare/`, `404.html`, `sitemap.xml`, `robots.txt`, `llms.txt` and the IndexNow key file are generated at deploy by `tools/build-pages.mjs _site` and never committed (`npm run build:pages` → `dist-pages/` to preview). Shared head/header/footer live in the script; after changing them run `node tools/build-pages.mjs --sync`. Config is `tools/site.config.mjs`; its `url` must equal `SITE_URL` in `js/site.js` and `goatcounter` must equal `GOATCOUNTER_CODE` in `js/analytics.js` (the build fails otherwise). Slugs are public URLs — don't rename them.
- **Service worker navigation**: only the scope root / `index.html` is mapped to the cached globe; every other navigation is network-first with a cached fallback. Never map all navigations to `./` again — it would serve the globe for `/countries/...`.

## Workflow

Owner's standing instruction: after finishing a change, open a PR, wait for CI, **merge it to `main` and confirm the Pages deploy** — unless told otherwise in that request.

## Testing

Unit tests run on Node's built-in runner (`npm test`, `tools/test/*.test.mjs`; `tools/test/register.mjs` maps `three` to the vendored copy and stubs `matchMedia`, so modules that touch the DOM or the renderer at import time, like `ships.js` or `globe.js`, can't be tested there). Verify changes by:
1. `npm run check` and `npm test`
2. Running the page and exercising the feature (Playwright works headless with `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`; it renders ~1 fps, so wait on frames, not time).
   `window.EarthInteractive` exposes `globe, layer, compare, spin, thrills, quiz, search, setView(), setLens(), compareKeys()` for scripted checks.
3. Checking desktop (1280×800) and phone (390×844) layouts.
4. `npm run preview:pages` then `npm run smoke` (`tools/smoke.mjs`, needs Playwright): 24 scripted checks over search, pin/tag, card, compare, lenses, views, quiz, recenter and deep links on both sizes.
5. `npm run qa` (`tools/qa.mjs`, BASE = a running dev server): ~65 checks per size with real taps on the globe (selection, card, compare UI + drag + share image, lenses, search, keyboard, games with Confirm/Enter and the miss line, daily, toggles, deep links, resizes, overlapping controls) and a warm-up leak check. ~20 min headless; wait on state (`globe.flight`, body classes), never fixed timeouts.

Layout rule: phones and desktop show the same controls and links (on phones the links sit in the brand's menu); panels (legend, quiz, compare) sit above the footer row and corner buttons, never over them.
